title: "Physical constants in units::constants"

The units library provides a set of physical constants with appropriate units attached, all defined as `precise_measurement` values in the `units::constants` namespace. Values follow the NIST 2018 CODATA recommended values and incorporate the 2019 SI redefinition where applicable. Constants with known measurement uncertainties also appear in `units::constants::uncertain` as `uncertain_measurement` objects.

## Using constants

Constants are `precise_measurement` objects, so they carry both a numerical value and a `precise_unit`. You can multiply, divide, and convert them like any other measurement.

```cpp
#include "units/units.hpp"
#include "units/physical_units.hpp"

// Access a constant
auto c  = units::constants::c;   // speed of light
auto me = units::constants::me;  // electron mass

// Derive a quantity
auto rest_energy = me * units::constants::c * units::constants::c; // E = mc²

// Convert to a specific unit
double joules = rest_energy.value_as(units::precise::J);
```

## Planck units

The Planck system of natural units is defined in the `units::constants::planck` namespace.

```cpp
#include "units/units.hpp"
#include "units/physical_units.hpp"

auto planck_length = units::constants::planck::length;
auto planck_mass   = units::constants::planck::mass;
auto planck_time_  = units::constants::planck::time;
```

| Symbol | Quantity |
|---|---|
| `planck::length` | Planck length |
| `planck::mass` | Planck mass |
| `planck::time` | Planck time |
| `planck::charge` | Planck charge |
| `planck::temperature` | Planck temperature |

Planck constants are accessible from strings using the bracket notation: `[planck::length]` or the shorthand `planckLength`.

## Atomic units

Atomic units (related to the electron or to atomic-scale measurements as defined by the BIPM) live in the `units::constants::atomic` namespace.

| Symbol | Quantity |
|---|---|
| `atomic::length` | Bohr radius (a₀) |
| `atomic::mass` | Electron mass |
| `atomic::time` | Atomic unit of time |
| `atomic::charge` | Elementary charge (same as `e`) |
| `atomic::energy` | Hartree energy |
| `atomic::action` | Reduced Planck constant (ℏ) |

```cpp
auto au_energy = units::constants::atomic::energy; // Hartree
```

Atomic constants are accessible from strings using `[atomic::length]` etc.

## Numerical constants

A handful of pure numbers are defined in `units::constants` as `constexpr double` values for use in unit definitions and conversions elsewhere in the library.

| Symbol | Value |
|---|---|
| `pi` | 3.14159265358979323846 |
| `tau` | 2π |
| `invalid_conversion` | signaling NaN |
| `infinity` | positive infinity |
| `standard_gravity` | 9.80665 (m/s²) |
| `speed_of_light` | 299 792 458.0 (m/s) |

```cpp
#include "units/units.hpp"

double circumference = 2.0 * units::constants::pi * radius_m;
```

## Constants with uncertainties

Several constants carry measurement uncertainties and are represented as `uncertain_measurement` objects in `units::constants::uncertain`.

| Symbol | Quantity |
|---|---|
| `uncertain::G` | Gravitational constant |
| `uncertain::eps0` | Permittivity of free space |
| `uncertain::u0` | Permeability of free space |
| `uncertain::H0` | Hubble constant |
| `uncertain::me` | Electron mass |
| `uncertain::mp` | Proton mass |
| `uncertain::mu` | Atomic mass constant |
| `uncertain::mn` | Neutron mass |
| `uncertain::Rinf` | Rydberg constant |
| `uncertain::alpha` | Fine structure constant |

```cpp
#include "units/units.hpp"
#include "units/physical_units.hpp"

auto G_unc = units::constants::uncertain::G;
double val  = G_unc.value();
double unc  = G_unc.uncertainty();
```

<Note>
A few uncertain constants have more decimal places than `uncertain_measurement` can store. They are included for completeness; the uncertainty field will be rounded to the supported precision.
</Note>

## Accessing constants from strings

Every constant listed here is available for string-based conversion by wrapping its symbol in square brackets.

```cpp
#include "units/units.hpp"

// Parse a constant by name
auto u = units::unit_from_string("[kcd]");   // luminous efficacy
auto p = units::unit_from_string("[planck::length]");
auto a = units::unit_from_string("[atomic::energy]");
```

<Tip>
String access to constants follows the same flag system as other string conversions. Pass domain or matching flags as the second argument to `unit_from_string` if you need to control matching behavior.
</Tip>
