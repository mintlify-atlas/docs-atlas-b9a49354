---
title: "Get started with the Units library"
description: "Go from zero to a working unit conversion in minutes — install the library, include a header, parse a measurement string, and convert to your target unit."
---

The fastest path to working code is a single header include and two function calls: `measurement_from_string` to parse user input and `value_as` to get the result in your target unit. This page walks through both C++ and Python from a clean start.

<Tabs>
  <Tab title="C++">
    <Steps>
      <Step title="Add the library to your project">
        The recommended approach for new projects is CMake FetchContent, which downloads and configures the library automatically. Alternatively, copy the headers directly for header-only use.

        <CodeGroup>

        ```cmake FetchContent (CMakeLists.txt)
        include(FetchContent)
        FetchContent_Declare(units
          GIT_REPOSITORY https://github.com/LLNL/units.git
          GIT_TAG        main
        )
        FetchContent_MakeAvailable(units)
        target_link_libraries(my_app PRIVATE units::units)
        ```

        ```cmake Header-only (CMakeLists.txt)
        # After copying units_decl.hpp, unit_definitions.hpp,
        # units_util.hpp, and units.hpp into your project:
        target_compile_definitions(my_app PRIVATE UNITS_HEADER_ONLY)
        target_include_directories(my_app PRIVATE path/to/headers)
        ```

        </CodeGroup>
      </Step>
      <Step title="Include the header">
        Add the primary header to your source file. All core types and functions are in the `units` namespace.

        ```cpp
        #include <units/units.hpp>
        using namespace units;
        ```
      </Step>
      <Step title="Parse a measurement from a string">
        `measurement_from_string` converts any unit string — such as `"45 mph"` or `"9.8 m/s^2"` — into a typed `precise_measurement`. This is the primary entry point for handling user input or configuration file values.

        ```cpp
        auto meas = measurement_from_string("45 mph");
        ```
      </Step>
      <Step title="Convert to your target unit">
        Call `value_as` with the target unit to get the converted `double`. An invalid conversion returns `constants::invalid_conversion` (a `NaN`), so you can guard with `std::isnan`.

        ```cpp
        double speed_mps = meas.value_as(precise::m / precise::s);
        // speed_mps ≈ 20.1168
        ```

        To check convertibility before converting:

        ```cpp
        if (!meas.units().is_convertible(precise::m / precise::s)) {
            throw std::invalid_argument("incompatible units");
        }
        ```
      </Step>
      <Step title="Perform arithmetic with measurements">
        Measurements support the standard arithmetic operators. Units are carried along automatically.

        ```cpp
        #include <units/units.hpp>
        using namespace units;

        measurement length1 = 45.0 * m;
        measurement length2 = 20.0 * m;
        measurement area    = length1 * length2;

        std::cout << "the area is " << area
                  << " or " << area.convert_to(ft.pow(2)) << ".\n";
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Python">
    <Steps>
      <Step title="Install the package">
        The Python wrapper is available on PyPI as `units-llnl`. It requires Python 3.10 or later.

        ```bash
        pip install units-llnl
        ```
      </Step>
      <Step title="Import and create a Unit">
        Construct a `Unit` from any unit string. Units are immutable objects, similar to Python strings.

        ```python
        from units_llnl import Unit

        u1 = Unit("m")
        u2 = Unit("cm")
        ```
      </Step>
      <Step title="Convert a value between units">
        Call `.convert(value, unit_out)` on a unit to convert a numeric value. You can pass the target as a `Unit` object or a string.

        ```python
        v1 = u1.convert(10, u2)
        assert v1 == 1000.0  # 10 m → 1000 cm
        ```
      </Step>
      <Step title="Work with Measurement objects">
        `Measurement` pairs a value with a unit. You can construct one from a string or from a value and unit, then do arithmetic directly.

        ```python
        from units_llnl import Measurement

        m1 = Measurement("10 m")
        m2 = Measurement("2.5 s")
        m3 = m1 / m2
        m4 = Measurement("4.0 m/s")
        assert m3 == m4
        ```

        To extract the value in a specific unit:

        ```python
        speed = Measurement("45 mph")
        mps = speed.value_as("m/s")
        # mps ≈ 20.1168
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Complete C++ example

The following is the canonical use case from the library documentation: a helper function that accepts a measurement string and returns the value in a standardized internal unit.

```cpp
#include <units/units.hpp>

double GetInputValueAs(const std::string& input, units::precise_units out)
{
    auto meas = units::measurement_from_string(input);
    return meas.value_as(out);
}
```

The return value is `NaN` (`constants::invalid_conversion`) when the conversion is not possible, so callers can check with `std::isnan(result)`.
