The Units library provides a powerful, flexible way to work with physical units of measurement at runtime. Developed at Lawrence Livermore National Laboratory, it handles conversions between hundreds of units, parses and generates human-readable unit strings, and supports complex scientific and engineering workflows — all within an efficient 8-byte unit representation.

## Why Units?

The Units library is designed for applications where the number and variety of units is large, units are provided at runtime (e.g., from configuration files or user input), and string-based unit handling is required. It is used in production by [HELICS](https://helics.org) and [GridDyn](https://github.com/LLNL/GridDyn) for power systems simulation.

## Getting started

<Steps>
  <Step title="Install the library">
    Add the Units library to your project via CMake FetchContent, as a submodule, or install the Python package from PyPI.

    ```bash
    pip install units-llnl
    ```

    ```cmake CMakeLists.txt
    include(FetchContent)
    FetchContent_Declare(units
      GIT_REPOSITORY https://github.com/LLNL/units.git
      GIT_TAG        main
    )
    FetchContent_MakeAvailable(units)
    target_link_libraries(my_app PRIVATE units::units)
    ```
  </Step>
  <Step title="Include the header">
    In your C++ source file, include the primary units header to access all types and functions.

    ```cpp
    #include <units/units.hpp>
    using namespace units;
    ```
  </Step>
  <Step title="Convert a unit from a string">
    Parse a measurement from user input and convert it to your internal unit standard.

    ```cpp
    auto meas = measurement_from_string("45 mph");
    double speed_mps = meas.value_as(precise::m / precise::s);
    ```
  </Step>
  <Step title="Perform calculations">
    Use measurement types for arithmetic — units are carried along and validated automatically.

    ```cpp
    measurement length = 100.0 * m;
    measurement time   = 9.58 * s;
    measurement speed  = length / time;
    std::cout << to_string(speed) << "\n"; // "10.438... m/s"
    ```
  </Step>
</Steps>
